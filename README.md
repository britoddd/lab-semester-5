## Getting Started
### Required Python Version
This whole code in this repository are run with **Python 3.10.9**  
#### Conda Installation
If you're using conda, you can create a new conda environment with conda:   
`conda create -n lab_semester_5 python=3.10.9`  
#### Global Python Installation
Otherwise, you can manually install python on:  
https://www.python.org/downloads/release/python-3109/

### Mandatory Python Libraries
It's highly recommended to create environment with the same version. If you used newer version of Python, the Tensorflow can't natively use the GPU Acceleration. Different version also can lead to error when compiling the program. All mandatory libraries has been listed below:
```
gymnasium==0.28.1
ipykernel==6.19.2
matplotlib==3.7.1
numpy==1.23.1
pandas==2.0.3
seaborn==0.12.2
scikit-learn==1.3.0
tensorflow==2.10.0
tensorflow-datasets==1.2.0
transformers==4.29.2
```
All the requirements above can be installed using Python Packages repository:  
`pip install -r requirements.txt`
### Git Clone
If you want to download all the codes into your own devices, your can use local Git   
`git clone https://github.com/britoddd/lab-semester-5.git`
